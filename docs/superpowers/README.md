# Design docs and plans (historical)

These are dated records of what was designed and decided at the time, kept as
written. They therefore refer to the project as **Keel**, its former name, and
use the old `keel-*` resource names and `keel` command.

They were deliberately left untouched by the rename to `bareboat` — rewriting a
dated design doc to describe a decision nobody actually made would make the
history misleading.

For current behaviour see [the guide](../GUIDE.md) and the [README](../../README.md).
